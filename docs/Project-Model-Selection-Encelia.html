Encelia Flower Model Selection

Motivation and Context

Encelia californica is a plant in southern California that is pollinated frequently by bees. They are known as the California Bush Sunflower. Encelia farinosa, also known as desert brittle bush, is native to California deserts and frequently confused with Encelia californica. Encelia californica has yellow ray flowers and brown disk florets while Encelia farnosa has both yellow ray flowers and disk florets, with lighter-grayer green leaves than Encelia californica. California Bush Sunflowers also tend to be bigger than brittlebush in most areas. Both are found in the Fullerton Arboretum, where we went on a trip to get experience collecting data within our school. Through predictive modeling, we are trying to figure out what best predicts these flowers.

Being able to distinguish between these two species would be useful since one is an actual sunflower while one is just a bush. Both have slightly different uses: for example, a California Bush Sunflower is useful for controlling erosion while a brittlebush is useful for glue.

Main Objective

The objective of this project is to be able to predict whether a flower is an Encelia californica or an Encelia farinosa using data that was gathered at the Fullerton Arboretum. Through four variables and a brief description of the differences between the flowers, we have an idea of what models we select. We are performing model selection in order to determine what is the best predictor of flowers.

Design and Data Collection

The data was collected from the Fullerton Arboretum by our class. We had 5 different pairs survey 20 different flowers each. We decided to track four variables: The number of rays/petals of the flower; the disk diameter, which is the diameter of the inside of the flower; the ray diameter, which is the diameter of a ray/petal in the flower, and the stem length, which was measured from the bottom to the top of the flower. Species is labeled as ‘F’ for Encelia farinosa or ‘C’ for Encelia californica.

One group forgot to measure stem length of the flowers that they sampled, which explains why some of the data values were NA. Additionally, it is very possible that some of these flowers are the exact same because different groups may have went to the exact same flower or a flower was surveyed twice. It is also possible that these are not exact measurements, and there may be different data for the same class. We have decided to round each numerical value that is continuous to the nearest tenth, whereas some other person may round to two decimal points. Also, we may have different definitions of the variables, such as stem length being only to nearest branch. We may also have different variables entirely from what another person chose, but we chose 4 variables, all numerical, whereas somebody may use a categorical variable such as the color of the disk floret. We did try to get flowers in various locations, as location can also affect characteristics of a flower.

Modeling

So, after looking at the graphs and summaries above, these are the following models I came up with that I feel like are really good predictors based on my explanatory data analysis:

  • Number of Rays

  • Stem Length

  • Stem Length + Number of Rays

  • Ray Diameter + Number of Rays

  • Ray Diameter + Disk Diameter

  • Stem Length + Ray Diameter

  • Ray Diameter

I also believe that doing a combination of Number of Rays, Ray Diameter, and Stem Length would also be a decent model to explore as the flowers. They have big differences in number of rays and stem length, and some variation in ray diameter, so I think combining these three would make for a great prediction. As I said in the context, Encelia Californica tend to be bigger than Encelia Farinosa, and those three attributes are what they tend to be bigger in.

Anyways, with the potential predictors being identified, we will perform logistic regression. Logistic regression is the probability that an observation is categorized as something. In this case, we are looking at the probability a flower is an Encelia Farinosa vs an Encelia Californica based on characteristics. This is done so that we see how well models can predict the species of the flowers and how effectively it can tell the difference between the two.

We start off by making some folds. These give us non-overlapping subsets of the training set that, with the exception of one, we will be testing our model on.

After we have made the folds, we will now use the models that I believe are good predictors of the plant species.

encelia_predictions <- function(split){
  # this function takes in cross-validated splits
  
  train <- analysis(split)
  valid <- assessment(split)
  
  glm_null <- glm(Species ~ 1, data = train, family = "binomial") # the null model is there, as always, to see which, if any, of those possible predictors are worse than the null model
  glm1 <- glm(Species ~ number_rays, data = train, family = "binomial")
  glm2 <- glm(Species ~ stem_length, data = train, family = "binomial")
  glm3 <- glm(Species ~ stem_length + number_rays, data = train, family = "binomial")
  glm4 <- glm(Species ~ ray_diameter + number_rays, data = train, family = "binomial")
  glm5 <- glm(Species ~ disk_diameter + ray_diameter, data = train, family = "binomial")
  glm6 <- glm(Species ~ stem_length + ray_diameter, data = train, family = "binomial")
  glm7 <- glm(Species ~ ray_diameter, data = train, family = "binomial")
  glm8 <- glm(Species ~ number_rays + stem_length + ray_diameter, data = train, family = "binomial")
  
  valid_predictions <- valid %>% 
    mutate(
      pred_null = predict(glm_null, newdata = valid, type = "response"),
      pred_num_rays = predict(glm1, newdata = valid, type = "response"),
      pred_stem_len = predict(glm2, newdata = valid, type = "response"),
      pred_stem_len_num_rays = predict(glm3, newdata = valid, type = "response"),
      pred_ray_dia_num_rays = predict(glm4, newdata = valid, type = "response"),
      pred_disk_dia_ray_dia = predict(glm5, newdata = valid, type = "response"),
      pred_stem_len_ray_dia = predict(glm6, newdata = valid, type = "response"),
      pred_ray_dia = predict(glm7, newdata = valid, type = "response"),
      pred_3 = predict(glm8, newdata = valid, type = "response")
    )
  
  return(valid_predictions)
}
mapped_predictions <- map(

I believe these are outliers and that they were either misclassified or are an oddity in a group of flowers that were predcited correctly otherwise.
