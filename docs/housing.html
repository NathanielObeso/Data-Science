Comparing Rent Prices in SoCal Housing and Making Inferences

Motivation and Context

Southern California has a lot of reasons for people to live there: Los Angeles is full of many areas to tour, though it also has a high crime rate. Meanwhile, Orange County is home to Disneyland, which is labeled as “the happiest place on earth”. Both counties also are home to beaches that attract tourists that have to travel and spend money doing so as opposed to people that live locally who can just drive to those beaches. My objective is to see if I can take any insight from house data in Southern California in the year 2025 to see if there is a difference between the prices in each county and do an inference on it.

Main Objective

The objective is to do some data wrangling to remove some prices that are clear outliers before doing analysis on the rest of the data. We are then going to make an inference about the relationship between price and county using Bayesian Statistics. We collected data on 7 variables: baths means number of bathrooms in the house while beds means the number of bedrooms in the house.

Design and Data Collection

The data was collected from somebody looking on Zillow for houses: it shows the city, price, beds, baths, area, type, and county that the data was collected in. This was collected at a specific date in 2025 (April 15), however, which very well could limit the analysis as it may not reflect things happening a month later when this project is finished. The variables also aren’t the best at giving insight as to why there may be a difference in prices between the cities because they only describe the house, not the other variables of the city.

Data Massaging

Something I noticed about the data was that SoCalRent2025 has commas and dashes in some of the observations of square feet. The variable sq ft is a character variable, so I had to make it numeric, but I had to change some things. First, I removed the commas from the numbers in the dataset to make them ready to be converted to a numeric variable.

SoCalRent2025 <- SoCalRent2025 %>% 
  mutate(
    `sq ft` = str_remove(`sq ft`, ",") #Remove commas in all numbers that have them
  )

That would make everything ready for converting square feet into a numerical variable, except that some of the entries in sq ft are what appear to be ranges with a “-” character. To do this, I ultimately decided to make two new variables: a minimum and a maximum variable for square feet so that both are represented to look at additional nuances of area.

SoCalRent2025 <- SoCalRent2025 %>% 
  mutate(
    min_sq_ft = if_else(str_detect(`sq ft`, "-"), 
    true = as.numeric(str_extract(`sq ft`, "[0-9]+")),
    false = as.numeric(`sq ft`),
    missing = NA), # Code to put the minimum square feet of the house, if there is a range of areas
    max_sq_ft = if_else(str_detect(`sq ft`, "-"),
    true = as.numeric(str_remove(str_extract(`sq ft`, "-[0-9]+$"), "-")),
    false = as.numeric(`sq ft`),
    missing = NA) # Code to put the maximum square feet of the house, if there is a range of areas
    )

Modeling

In order to see the true relationship, let’s do some Bayesian Inference.

bayes_SoCalRent <- stan_glm(
  price ~ county,
  data = SoCalRent2025_1,
  family = "gaussian",
  prior = normal(location = 3, autoscale = TRUE),
  prior_intercept = default_prior_intercept(),
  seed = 1
)

Predicted rent prices are pretty interesting, I experimented with a few priors, but all of them predicted negative rent price, so I just went with what I felt worked best.

bayes_SoCalRent |>
  posterior_interval(
      pars = c("countyOC", "countyRIV"),
      prob = 0.90
    )
                  5%        95%
countyOC   -100.7536   842.4131
countyRIV -2094.6339 -1135.4284

We can see that there is a 90% chance that the slope of the population model, assuming everything else stays constant, for an Orange County house compared to one in LA is between -100.7536 and 842.4131. This implies that there is no distinct difference in prices between the counties of LA and OC. There is also a 90% chance that the slope of the population model, assuming everything else stays constant, for a Riverside house compared to one in LA is between -2094.6339 and -1135.4284, meaning that Riverside houses tend to be cheaper to rent than LA houses.

Conclusion

Los Angeles County and Orange County are both great places to live in, and the rent of the houses in those places are very similar. There doesn’t appear to be a significant difference between the two counties. Riverside houses are much cheaper, but they also don’t offer the same things both Los Angeles County and Orange County do.

Limitations

The data was collected on a specific date, so things may have changed by then. The problem is since they can change on a day-by-day basis, the data is not always the most accurate since houses can be taken off or rent could go up. Also, as mentioned earlier, there isn’t variables that are about the city, as the only one I could think of that was in the dataset with any real impact was square feet, and I didn’t feel like there was much of a difference between the counties’ average square feet.
